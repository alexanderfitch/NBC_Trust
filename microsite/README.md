# microsite

The public, SEO-driven succession microsite on the NBC Trust domain (PLAN.md Stage C/D).

Status: **infrastructure being built against placeholder content.** Sam owns the real copy and
Drew the videos; nothing here waits on them. Every placeholder is marked `PLACEHOLDER` so a
grep finds all of them at integration time.

- `src/` — the site itself.
- `content/` — copy, versioned. Sam's copy lands here; placeholders live here until it does.
  Versioning copy is a compliance requirement, not tidiness (PLAN.md Stage F1).
- `assets/` — video poster frames, images, the downloadable checklist PDF.

Public-facing copy requires compliance-attorney review before launch. Nothing in this directory
ships without it.
